# Gazebo 世界（gazebo_world.md）

三个自建 SDF 世界（diy_nav_gazebo/worlds/），纯基本几何体，零 Fuel 依赖
（内联地面 + 方向光）。

## empty_world.world
16×12 m 地面 + 光照，用于接口/漂移等基础测试。

## simple_world.world（10×8 m）
- 四周墙体 + 中央障碍（2.2, −0.5，1.2×0.9 m）+ 2 个箱体
- 直角弯通道（≥1.0 m）
- 起点区（(0,0) 2×2 m 无碰撞）+ 3 个目标区薄圆柱（无碰撞）

## complex_world.world（16×12 m）—— 主测试环境
```
上排房间 R1/R2（x=0 分隔墙）、下排房间 R3/R4（x=2.5 分隔墙）
走廊：y∈[−0.75, 0.75]，1.44 m 净宽（墙内壁 ±0.72）
门口：R1 宽 0.8 m（窄通道考验）/ R2 宽 1.2 m / R3、R4 宽 1.0 m
U 形障碍（R2，开口朝西）、L 形障碍（R4）
遮挡大箱体（R3，形成激光遮挡区）、多独立箱体
危险区（R4，红色薄片，无碰撞）
起点区 (0,0) 2×2 m 无碰撞 + 6 个目标区薄圆柱（无碰撞）
```

## 世界自检（阶段 6 记录）
- 通道宽度均 ≥1.0 m；窄门口 0.8 m（机器人宽 0.36，余量 0.22 m/侧）
- 起点区无障碍；目标点无碰撞
- 激光覆盖：R3 遮挡箱体后方为建图盲区（对比实验的考察点）
